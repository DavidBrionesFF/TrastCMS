# Comunidad

## Código de conducta

TrastCMS sigue un código de conducta basado en el Contributor Covenant. Esperamos que todos los participantes:

- Sean respetuosos y profesionales.
- Acepten críticas constructivas.
- Se enfoquen en lo mejor para la comunidad.
- Mostrar empatía hacia otros miembros.

Comportamientos inaceptables:

- Acoso, insultos o comentarios despectivos.
- Difusión de información privada.
- Conducta profesional inapropiada.

Reporta violaciones a través de GitHub Security Advisories o contactando a los maintainers.

## Roles y responsabilidades

### Maintainer

- Aprueba y fusiona Pull Requests.
- Define la hoja de ruta y prioridades.
- Gestiona releases y versiones.
- Resuelve conflictos en la comunidad.

### Colaborador

- Envía Pull Requests siguiendo `CONTRIBUTING.md`.
- Revisa código de otros contribuidores.
- Reporta bugs y propone mejoras.
- Actualiza documentación.

### Usuario

- Reporta bugs con plantillas de issues.
- Prueba releases beta.
- Comparte feedback y casos de uso.
- Promueve el proyecto en la comunidad.

## Proceso de contribución

1. **Issue**: Discute la propuesta en un issue antes de codificar.
2. **Branch**: Crea una rama desde `master` con prefijo descriptivo:
   - `feat/`
   - `fix/`
   - `docs/`
   - `refactor/`
3. **Código**: Sigue `docs/CODE_STYLE.md`.
4. **PR**: Abre un Pull Request con descripción clara.
5. **Review**: Un maintainer revisará y solicitará cambios si es necesario.
6. **Merge**: Una vez aprobado, el maintainer fusiona el PR.

## Reconocimiento

Los contribuidores se reconocen en:

- El archivo `CHANGELOG.md` (si aplica).
- La sección de agradecimientos en releases.
- Mención en issues y PRs fusionados.
