# Changelog

Los cambios relevantes del proyecto comunitario se documentan aquí. TrastCMS utiliza versiones semánticas y distribuciones completas; no requiere aplicar paquetes incrementales.

## 3.6.1 — 2026-08-29

### Añadido

- Administración multisitio con resolución segura por host y puerto.
- Membresías, roles, contenido, medios, configuración y plugins aislados por tenant.
- Plugins incorporados para cuenta, academia, comentarios, CRM, mantenimiento, newsletter, pagos, SaaS, tienda, traducción y viajes.
- Panel Vue 3, editor de contenido, constructor visual, biblioteca multimedia y portal de desarrolladores.
- Integración REST, OpenAPI y servidor MCP contextual por tenant.
- Guías comunitarias para instalación, arquitectura, plugins, temas, Nginx y Certbot.

### Temas comunitarios

- Aurora.
- Coffee.
- Midnight.
- Nexus.

### Seguridad y operación

- Sesiones con CSRF y autorización validada en backend.
- Hosts desconocidos resueltos en modo cerrado.
- Configuración sensible y datos runtime excluidos de Git.
